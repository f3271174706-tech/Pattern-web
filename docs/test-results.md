## 浏览器实测

1. JSON 文件导入 → 定位 → 修改 (1,1) → 材料统计 → 历史差异 → SVG/PDF 下载 → 刷新 → 撤销 → 刷新 → 重做。
2. 矩形批量替换预览与取消不修改数据库；确认后只改变指定的两格。
3. 新建 200×200 MARD 图纸、写入白色 H2、更新拼板排版、缩放与平移，矩阵内容保持一致。
4. 非法色号显示 `/grid/cells/0/0`；平板宽度可打开与关闭对话框。
5. 画笔、橡皮、吸管及矩形拖选在实际 Canvas 中命中预期格子；区域修改后逐格核对 JSON。
6. 密集 200×200 棋盘色图：40,000 颗珠子、两种色号各 20,000、16 个 50×50 拼板；导入、显示、缩放和平移测试用例总计 2.1 秒。

性能结果是当前机器上的可用性检查，未声称固定帧率、跨设备相同延迟或 500×500 已完成性能验收。
